Structured analysis for senior capstone software at STI College CDO.

As the Systems Analyst, my responsibilities encompass requirement elicitations, domain modeling, identifying key entity lifecycles, establishing normalization standards (up to 3NF), and maintaining strict architectural alignment between business rules and engineering implementations.

Role Area Deliverables / Scope Validation Method
Requirements Engineering Functional & Non-Functional specifications, constraints Stakeholder interviews & Matrix tracing

Workflow Specs Use Case narratives, Activity flows, State transitions UML 2.5 standards & Actor mapping

Data Flow Diagram (Level 0 Context & Level 1 Decomposition)

System process boundary and data flow transformations.

0.0 CONTEXT
External Entities (User, Admin, System Auditor)

Entities supply authentication inputs, search parameters, and transactional commands across secure SSL boundaries.

1.0 AUTH
Authentication & Session Token Verification

Validates credentials against `tbl_users`, generates JWT session token, and asserts role access matrix.

2.0 PROCESS
Core Transactional Logic & Data Validation

Sanitizes payloads, enforces business logic constraints, and triggers transactional write locks on MySQL database.

3.0 AUDIT
Audit Logging & Real-time State Synchronization

Logs operation metadata to `tbl_audit_logs` and returns normalized JSON response payload to client frontend.
